# Paper & Appendix Alignment (Double-Blind)

Use this checklist to align the manuscript with the release bundle.

## Manuscript requirements

- State explicitly that **manual review is part of the benchmark** and why automated scoring is insufficient.
- Report review statistics (reviewer count, IAA, adjudication rate, audit coverage).
- Describe the release scope and note excluded private author materials.
- Cite the benchmark using `CITATION.cff` (anonymized for review).

## Appendix recommendations

- Include the review SOP summary and a minimal example of the structured template.
- Provide sample evidence excerpts (sanitized) that illustrate review judgments.
- List limitations and known failure modes of the manual review process.
