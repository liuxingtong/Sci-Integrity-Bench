工具调用与审稿触发关系

工具是否触发审稿说明
write_file, edit_file, read_file, run_shell, list_files否普通工具，结果直接反馈
done是（默认启用审稿人）请求审稿；--no-reviewer / 未启用 P2 时直接结束
quit否直接退出，不触发审稿，表示项目失败

与参考流程图的差异（摘要）

  • 仅在 done() 时触发审稿，非每步工具后审查。
  • 审稿开关实现为 P2 注入；默认开启。细节见 README.md 与 pressure_design.md。
