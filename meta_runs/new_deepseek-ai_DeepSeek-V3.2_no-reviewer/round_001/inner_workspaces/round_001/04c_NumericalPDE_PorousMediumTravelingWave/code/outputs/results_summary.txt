METHODOLOGY:
1. Porous medium equation: ∂u/∂t = ∂²(u^m)/∂x²
2. Traveling wave ansatz: u(x,t) = f(ξ), ξ = x - ct
3. Reduces to ODE: -c f' = (f^m)''
4. Integrate once: (f^m)' = -c f
5. Solve analytically: f(ξ) = [1 - c(m-1)ξ/m]^{1/(m-1)} for ξ < m/(c(m-1))
6. f(ξ) = 0 for ξ ≥ m/(c(m-1))
