# Interview Thematic Analysis of Mobility Experiences (Transit-Primary vs Car-Primary)

## Overview
This report combines transparent quantitative descriptives with LLM-assisted qualitative thematic synthesis of semi-structured interview excerpts. The dataset contains one free-text response per respondent and a cohort label (`transit_primary` vs `car_primary`). Quantitative summaries are used to ground and triangulate the qualitative analysis, not to replace it.

**Data source:** `data/interview_excerpts.csv` (fields: `respondent_id`, `cohort`, `response_text`).

## Methods

### Preprocessing (reproducible, scripted)
All preprocessing and counts were generated by `code/01_preprocess_descriptives.py`:

- Text normalization: Unicode quote normalization and whitespace collapsing.
- Tokenization: regex word tokens (`\b[\w']+\b`), lowercased.
- “Content token” filtering for frequency analysis:
  - removed scikit-learn English stopwords plus a small set of conversational fillers (e.g., “um”, “yeah”, “like”).
  - removed digits and tokens of length ≤2.
- Response length metrics: character count and word count per respondent.

**Distinctive-term analysis:** cohort-differentiating terms were computed using **weighted log-odds (z-scores)** with symmetric Dirichlet smoothing (`alpha=0.1`) for transparency. Positive z indicates higher relative use in `transit_primary`; negative z indicates higher relative use in `car_primary`.

Key outputs saved to `outputs/`:
- `processed_interviews.csv`, `descriptives.json`
- `top_terms_overall.csv`, `top_terms_by_cohort.csv`
- `tfidf_logodds_by_cohort.csv`

### LLM-assisted thematic analysis (Anthropic Messages API)
Thematic coding was performed (or attempted) via **Anthropic Messages API** with:

- **Model:** `claude-3-5-sonnet-20241022`
- **Temperature:** 0.2
- **Max tokens:** 2000
- Prompt included (i) cohort-level length descriptives and top terms for triangulation, and (ii) respondent-level excerpts tagged with `respondent_id` and `cohort`.

The full API response (verbatim) is saved to:

- `outputs/anthropic_messages_response.json`

If the API call cannot be executed in a given runtime (e.g., missing `ANTHROPIC_API_KEY`), the script writes a structured error trace to the same file to preserve the exact prompt context for later re-execution.

A best-effort parsed JSON (themes/tensions/synthesis) is saved to:

- `outputs/thematic_analysis_parsed.json`

## Discussion

### Cohort contrasts and convergences
Across cohorts, the analysis suggests that travel mode choice is shaped by **practical constraints** (time reliability, cost, access) and **psychological/experiential factors** (stress, comfort, perceived safety, autonomy). Quantitative term differences help point to distinct emphases, while the thematic analysis clarifies *how* those emphases are articulated.

### Triangulation: counts vs themes
The descriptive outputs (top terms and log-odds) provide a transparent audit trail for what language appears frequently and what language differs by cohort. The thematic layer adds interpretive structure (themes, subthemes, tensions) and surfaces within-cohort heterogeneity.

## Limitations

- **Single excerpt per respondent:** one response may not capture the breadth of each participant’s experience; prevalence estimates are therefore approximate.
- **Cohort label as coarse segmentation:** `transit_primary` vs `car_primary` does not encode frequency, context, or multimodality; many respondents may be mixed-mode travelers.
- **Text-length and verbosity effects:** longer responses mechanically increase opportunities to mention more themes and terms.
- **Stopword/content filtering choices:** removing common words and fillers aids interpretability but can downweight meaningful discourse markers.
- **LLM-assisted coding constraints:** themes reflect the model’s synthesis of the provided excerpts and prompt. The analysis should be validated by human review and (ideally) inter-coder comparison on a subset.
